onlineShopping

Food-ordering platform: an admin console for the restaurant and a mobile front for customers.

Admin consoleDishes, setmeals, categories, employees and orders (desktop browser). Customer frontMenu, cart, address book and checkout (best viewed in a phone-sized window). API docsKnife4j UI over the OpenAPI description; Swagger UI is at /swagger-ui.html. HealthLiveness / readiness probe used by Docker Compose.
Demo accounts are documented in the project README.
